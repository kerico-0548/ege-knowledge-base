# Методы решения задач

Откройте **Открыть методы.html**. В нём есть поиск по номеру и способу решения, ссылки на PDF, Python и Excel.

В каждом PDF сначала приведена схема ваших методов, затем исходные примеры. Несколько способов сохранены раздельно. Ошибки исходников отмечены явно. В Python-файлах исходные фрагменты изолированы в функциях; импорт не запускает задачи. В конце части файлов находятся отдельно проверенные базовые блоки.

Новые Excel-примеры для № 3, 9, 18 и 22 показывают восстановленный метод на учебных числах. Авторская книга 19–21 и две книги №26 сохранены отдельно.

Оригиналы находятся в «Для обучения» и не изменены. Новые файлы будут обработаны при следующем обращении; автоматическое слежение не настроено.
