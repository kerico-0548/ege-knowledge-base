Публикация на сайте

Черновик виден только в этом браузере. Публикация обновит справочник для всех учеников.

Ключ нужен только на время отправки. При создании выбери репозиторий ege-knowledge-base и право Contents → Read and write. Создать ключ на GitHub ↗

Опубликовать через сайт GitHub без ключа
  1. Скачай файл с текущими правками.
  2. Открой папку справочника на GitHub, перетащи туда materials.js и нажми Commit changes в ветку main.
