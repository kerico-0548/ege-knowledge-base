Где брать задания и чему верить

Для формата экзамена, для объяснений и для тренировки нужны разные материалы. Разберём на одном примере, куда идти с каждым вопросом.

Проверяй год и тему

Допустим, в старом курсе номер задачи расходится с новой демоверсией. Открой на ФИПИ комплект своего экзамена и года. Найди предмет, сравни формулировку, проверяемое умение и формат ответа. Выпиши тему словами. Так старый разбор по двоичной системе останется полезным, даже если в новом варианте тема стоит под другим номером.

Три ссылки для самостоятельной работы

КОМПЕГЭ пригодится, когда хочется решить незнакомый вариант ЕГЭ на компьютере. Выбирай нужный учебный год и смотри, кто составил вариант. В моём курсе Stepik «ЕГЭ Информатика 2025» уроки по задачам 1–23 можно проходить по темам. В моей базе на GitHub Pages удобно открыть условие и сравнить способы решения. Все три ссылки собраны ниже.

Хороший порядок на вечер: выбрать тему в курсе → попробовать незнакомую задачу → открыть разбор, если упёрся в конкретный шаг. Для ОГЭ начни с отдельной демоверсии ФИПИ. Вариант ЕГЭ для такой диагностики слишком далеко от твоего экзамена.

Как проверить ответ из поиска или нейросети

Спроси, о каком годе и предмете идёт речь. Утверждение о правилах сверь с оригинальным документом. Код проверь на маленьком примере с известным ответом. Например, формула «последний элемент range равен правой границе» опровергается запуском list(range(2, 5)). Непонятный вывод сохрани вместе с источником и принеси на занятие.
