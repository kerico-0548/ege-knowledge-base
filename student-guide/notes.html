Справочник для учеников

Конспект, по которому можно себя проверить

Одной короткой записи хватает, если через неделю по ней можно восстановить ход решения. Бумага, заметка в телефоне и файл с кодом подходят одинаково.

Оставь четыре строки

Вопрос — что я хочу уметь? Правило — какое действие для этого выполняю? Пример — где это сработало? Ловушка — где я уже ошибался? В тетради вопрос удобно писать слева, ответ справа и закрывать его листком. В электронном конспекте оставляй в заголовке название темы, чтобы найти запись поиском.

Вот готовая карточка по Python

Вопрос: какие числа перебирает range(2, 5)? Правило: начинаем с 2, заканчиваем перед 5. Пример: получим 2, 3, 4. Ловушка: чтобы включить 5 при таком шаге, придётся написать range(2, 6). Закрой ответ и попробуй предсказать результат для range(3, 7). Проверь запуском: 3, 4, 5, 6.

Проверь запись на другом предмете

Для русского запиши одно предложение, расставь знаки и подпиши основание для каждого. Для истории задай на лицевой стороне вопрос о причине события, на обороте запиши связь и один пример. Если не удаётся ответить, допиши недостающую мысль своими словами.

Через несколько дней открой только вопросы. Пометь записи, где пришлось подсмотреть. В следующий короткий повтор возьми именно их и одну старую тему, которую, кажется, уже помнишь.
