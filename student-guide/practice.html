Как решать задачу после видеоразбора

Пока смотришь, каждый шаг кажется понятным. Проверь, сможешь ли ты восстановить решение, когда вкладка закрыта.

Сначала попробуй сам

Перескажи условие своими словами. Выпиши входные данные и то, что должно получиться. Возьми такой маленький пример, чтобы его можно было посчитать на бумаге. Хочешь узнать количество чётных в списке? Для чисел 2, 5, 8 ожидаемый ответ — 2.

Открывай разбор до первого непонятного шага

Например, ты уже умеешь перебирать числа, но увеличиваешь счётчик на каждой итерации. Посмотри только фрагмент про условие. Закрой разбор и напиши цикл заново. Проверь его на списке 2, 5, 8, затем на 5, 7. У второго примера ожидаемый ответ — 0.

Если результат расходится с ожиданием, выпиши рядом с каждым числом текущее значение счётчика. Место, где он впервые изменился зря, подскажет, какую строку проверить.

Измени условие

Посчитай теперь числа, которые одновременно чётные и больше пяти. В списке 2, 5, 8 останется одно. На следующем занятии реши аналогичную задачу с чистого листа. Для геометрии можно закрыть образец доказательства, нарисовать свой чертёж и объяснить, где используется каждое условие.

Попробуй сегодня

Подбери для своей программы два теста: обычный и такой, где ответ равен нулю. Подпиши ожидаемые ответы до запуска.
