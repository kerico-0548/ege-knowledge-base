# Как пополнять базу знаний

## Быстро добавить в свой браузер

Нажми «Добавить», выбери номер задания и перетащи файлы. Word, PDF, презентации и таблицы получают текстовое представление, изображения распознаются. Исходные файлы сохраняются отдельно.

Эти загрузки и личные правки находятся в этом браузере. Для переноса на другой компьютер открой «Мои материалы», скачай резервную копию, затем восстанови её там. Копия содержит и файлы, и заметки, и редакции кода.

## Дополнить общую версию сайта

В «Моих материалах» нажми «Добавить файлы в GitHub». В открывшейся папке выбери Add file / Upload files, добавь документы и сохрани изменения. Через несколько минут они появятся на сайте.

Номер в начале названия помогает распределить файлы: например, «24 — строки.docx» или «27 — новая кластеризация.pptx».

Для общих правок к существующим карточкам нажми «Подготовить правки для общей базы». Добавь получившийся JSON-файл в ту же папку на GitHub. Полную ZIP-копию также можно добавить туда.

## Единая структура разбора

Условие: полный текст, ограничения, исходные данные и важные таблицы.

Решение: выбранный метод, последовательность действий, редактируемый код или расчёты Excel.

Ответ: результат и источник его проверки.

Если у задачи несколько способов, сохраняй ручной, Excel и Python отдельно. Изменённое условие или новый код нужно проверить заново. Автоматическое распознавание картинки не является проверкой ответа.

Старое №27 в базу не добавляется. Для графиков координаты берутся из исходных данных, а не угадываются по изображению.
