# Новые материалы

Загрузи сюда учебные файлы через кнопку **Add file → Upload files** в GitHub. Можно сразу несколько. После сохранения изменений сайт автоматически обновится.

Поддерживаются PDF, Word DOCX, PowerPoint PPTX, Excel XLSX, Python, Кумир, TXT, Markdown, CSV и изображения. Номер задания в начале названия помогает распределить материал, например `24 — мой разбор.docx`.

Для переноса правок из сайта сюда можно добавить `правки-базы.json` или ZIP резервной копии, созданный в разделе «Мои материалы». Автоматический перенос и распознавание не делают новый материал проверенным решением.

Не добавляй файлы ключей и паролей. Эта папка входит в публичную базу.
