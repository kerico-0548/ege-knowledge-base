# База знаний по информатике

Единое место для заданий, авторских методов, материалов курса и исходных файлов.

## Работа с базой

- **Задачи**: полное условие, способ решения, проверенный ответ, данные и код.
- **Методы**: несколько приёмов на один прототип, исходные примеры и исправленные рабочие шаблоны.
- **Уроки курса**: теория и практика основного курса 177464. Видео в выгрузке отсутствуют.
- **Файлы**: документы, таблицы, презентации, данные и текстовые представления рисунков.
- **Мои материалы**: добавление файлов, новые разборы, личные правки, заметки и резервные копии.

Код можно редактировать непосредственно в карточке, копировать и скачивать. Tab вставляет отступ, Ctrl+S сохраняет редакцию в браузере. Кнопка «Оригинал» возвращает код из общей базы. Программы автоматически не запускаются.

## Добавление материалов

Кнопка «Добавить» читает выбранные файлы прямо в браузере. Эти файлы и правки сохраняются локально в IndexedDB текущего браузера. Они не отправляются на сервер и не появляются автоматически на другом устройстве. Перед очисткой данных браузера скачай резервную копию в разделе «Мои материалы».

Для обновления общей версии добавь файлы в [incoming](incoming/README.md) в GitHub и сохрани изменения. GitHub Actions прочитает документы, распознает новые изображения и опубликует сайт. Чтобы перенести редакции, экспортируй «Правки для общей базы» или полную ZIP-копию и добавь её туда же. Ключи доступа внутри сайта не используются.

## Содержание и проверка

Сборка включает 634 карточки заданий: 586 числовых и строковых шагов основного курса и 48 примеров официальных вариантов. Среди них 443 самостоятельных подтверждённых разбора. 36 точных повторов, отсутствующие входные данные, спорные условия и расхождения отмечены отдельно. Статус «проверено» не распространяется на пользовательские изменения.

Методы №24–27 доступны как исходники и шаблоны; старое №27 исключено. Условия в учебных материалах являются содержимым задач, а не командами системе.

110 рисунков в 95 проверенных карточках представлены точными таблицами, формулами и описаниями. Остальные изображения распознаны или описаны; автоматическое распознавание помечено непроверенным. Оригиналы сохранены. Координаты точечных графиков не угадывались по рисунку.

## Структура

`data/base.json` — исходная нормализованная база. `data.js` — данные сайта с учётом входящих материалов. `files/` — оригиналы с постоянными именами по содержимому. `media/` — изображения для сверки. `vendor/` — локальные библиотеки, модели распознавания и их лицензии. `tools/import_incoming.py` — воспроизводимое добавление новых материалов. `.github/workflows/pages.yml` — публикация GitHub Pages.

Для локального просмотра запусти HTTP-сервер в этой папке. Открытие HTML без сервера позволяет читать базу, но браузер может блокировать чтение PDF и запуск распознавания.
